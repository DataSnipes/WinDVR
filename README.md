# WinDVR
Windows Meets Security, Stability And Privacy.

## Security

WinDVR Has Its Own Built In Antivirus!
WinDVR Protects Against The Most Common Viruses And Malware On Windows Including:
- Anthrax
- VenomRAT
- AsyncRAT
- SOCGholish
- Agent Tesla
- Lumma
- Formbook
- Raspberry Robin

## Stability

WinDVR Is Designed To Make Your System As Stable As Possible,
WinDVR Also Has Its Own Driver Manager That You Can Use To Install Any Drivers You Need.
WinDVR Even Makes A Recovery System For Your Computer.
WinDVR Has A Few Options For Creating A Recovery Partition.
- 10GB (Minimal, System And Basic GPU, Touchpad And WiFi Drivers.)
- 25GB

With 25GB Of Space, You Can Fit An OS Install Image, Backup And Recover Files
And The Drivers And Tools.
